喜多村研究室 システムは、喜多村研究室メンバー向けの環境です。利用には外部の第三者からの申請を区別するため申請と管理者による確認が必要です。

本ガイドでは、システムの利用対象と申請方法を説明します。承認され、管理者から接続の案内を受け取ったら、[Coder Workspace](../coder/)と共有GPUを利用できるようになります。

## 申請前の確認

- 申請フォームへ回答には大学Gmail
[利用申請フォーム](https://forms.gle/eJqGfB4XF7RhY4pM7)は、大学Gmailアカウントでログインして開き、画面の質問に回答して送信してください。

申請フォームで回答する内容は、おおまかに次の通りです。

- 学生アカウントの情報
- Coderの認証に使うGitHubアカウント
- 利用したいシステムや研究での用途

:::note
申請を完了したら、画面の送信完了表示を確認してください。送信完了が表示されない場合は、フォームを最初から開き直して再送信してください。
:::

## 申請後の流れ

1. 管理者が申請を確認します。
2. 承認後、Github組織への招待が届きます。
3. 接続に必要な情報が個別に案内されます。
4. 案内に従って準備し、Coderへログインします。

承認までにかかる時間や、申請状況の確認先は、管理者から案内された連絡先へ問い合わせてください。申請を送信しただけでは、すぐにシステムへ接続できません。

:::note
この公開ドキュメントに接続先が掲載されていないのは、Coderが一般公開されたサービスではないためです。接続先や招待情報は、承認された利用者にのみ個別に案内します。
:::
