喜多村研究室が提供する開発環境、GPU、AI研究基盤の利用ドキュメントです。利用を始める場合は、[利用対象と申請](getting-started/application/)から順番に進めてください。

## 研究のための共通基盤

喜多村研究室では、個人のPCごとに開発環境を作り直す代わりに、研究室が管理する共通の計算環境を利用できます。Coder上の独立したWorkspaceから、ブラウザやVS Code Desktopで研究コードを実行できます。Workspaceは必要時に起動され、保存されたファイルはWorkspaceごとに保持されます。
