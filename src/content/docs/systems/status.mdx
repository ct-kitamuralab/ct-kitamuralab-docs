## Statusの意味

| Status | 意味 |
| --- | --- |
| 提供中 | 承認された対象者が現在利用できます |
| 準備中 | 提供方針があり、設定や運用方法を整備しています |
| 検討中 | 実現方法や必要性を評価しています |
| デモ開発予定 | 研究基盤の活用例としてデモを計画しています |
| 実験候補 | 検証対象の候補であり、提供は決定していません |

:::note
準備中、検討中、実験候補の機能について、提供時期は確定していません。利用可能になった機能はこのページで案内します。
:::
